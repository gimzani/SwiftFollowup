# Color Picker Input

The **ColorPickerInput** component has a dependency on <a href="https://linx4200.github.io/vue-color/" target="_blank">vue-color</a> - so don't forget to import the correct styles.

```js
import 'vue-color/style.css';
```

Then you can use the Component like this:

```xml
<ColorPickerInput v-model="colorValue" /> 
```
