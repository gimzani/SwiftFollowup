
# Google Fonts Tools

This package is for loading and displaying Google Font libraries both staticly and dynamicly.


Components

Prop |  description |
|----|----|
| useGoogleFonts | composable that manages functionality for GoogleFont management |
| GoogleFontSelect | component for selecting a font |
| GoogleFontDisplay | component for viewing selected fonts |
